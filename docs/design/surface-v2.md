# Creative production console

Mode: Operate. User: local creative-production operator. Primary tasks: find a run, inspect its stage/material, review outputs, create new work.

## Direction contract

THESIS: A resource console with page-based navigation replaces the inherited list/detail split and slide-in creation form.

OWN-WORLD: White global chrome, cool gray working canvas, 214px navigation, orange actions, blue resource links, 1px neutral rules and 4px controls. System UI type serves extended operational use.

STORY: Find the task in a complete table; open its own page; inspect the reference and execution stages. Create in three explicit steps, retaining values when returning to earlier steps.

FIRST VIEWPORT: A fixed 62px global header, left navigation, and full-width content with breadcrumbs, a compact page label/action row, state filters and one task table. No automatically selected detail pane. Signature interaction: task routes survive reload and browser back; a guided creation route replaces overlay focus confinement.

FORM: User-pinned Cloudflare-inspired minimal resource console; no random catalog selection. Source of direction is the user's request in this chat. Motion is limited to state feedback and narrow-screen navigation, with reduced-motion support.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Review verdict and scope limits: see `review-v2.md`.
