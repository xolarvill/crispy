# Crispy UI direction — first review

Operational workspace for creative production. Users need to find a task, inspect its product/material/stage, and approve or reject work with minimal navigation. Desktop use assumes an ordinarily lit workspace and extended review sessions: light neutral surfaces, restrained forest green, fine rules, readable workhorse UI typography.

- No H1 or H2 elements anywhere in the new frontend, including dialog titles.
- No marketing slogans, redundant descriptions, fake performance metrics or decorative dashboard cards.
- Lucide icons for familiar actions, with accessible names and tooltips; retain short text for critical submit actions.
- shadcn source-owned components and semantic tokens form the base. Fluid Functionalism informs purposeful, interruptible interactions; Aceternity is reserved for product-relevant visual moments. Neither reference library has been installed in this first preview.
- Primary layout: 216px navigation, flexible task list, 390px review pane. Small screens use full-width detail and collapsible navigation.
- Explicit demo/live mode. Never replace failed live requests with fabricated data.
- Respect reduced motion, keyboard focus, form labels, loading/error/empty states.

First review scope: task workspace, creation drawer, detail/stages and product references. Existing business services and legacy dashboard remain available during migration.
