# 内容审阅

锁定本次审阅的产物和版本、用户指定范围、渠道及最新决定。只检查能影响当前交付的事项；用户要改一句话时不自动增加平台发布验收。

检查所需依据：已确认的产品知识、适用证据、品牌样例、优惠条件、素材可使用范围及实际链接。缺少证据时定位具体主张；不因某项缺失笼统判定所有内容不可用。

## 表达与事实一起处理

优先解决读者会误解、事实冲突、行动入口错误或交付不可用的问题。反馈指向段落、字幕、画面或时间段，说明影响及修改建议。保留已经清楚且准确的文字，不为了展示工作重写全部。

需要渠道规格、广告资格或邮件要求时，核实当前官方来源。区别已验证失败、未检查项和风格建议；诊断清单的存在不能证明素材通过检查。

输出按请求给出修订稿或审阅意见，保留关键事实变更依据。明确被检查版本及尚影响交付的缺项；不要例行附加没有实际问题支持的免责声明。

人工批准必须对应具体版本。后续修改正文、媒体、优惠、受众或发布目标时检查原批准是否仍适用，按真实授权处理。自己的“检查通过”不写成人已批准，现有 `VariantReview`/审阅 API 的写入也不自动执行。
